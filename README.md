# NexusLink Corporate Website

Static multi-page corporate website for NexusLink.

Pages:

- `index.html` - Home landing page
- `du-lich.html`
- `vat-tu.html`
- `ky-thuat-dau-khi.html`
- `chuyen-doi-so.html`
- `lien-he.html`

## Run locally

```powershell
cd nexuslink-landing
node server.mjs
```

Open: http://127.0.0.1:4173

## GitHub Pages

This is a static website. It can be deployed to GitHub Pages from the repository root or from this folder after the files are pushed.
